# 销量规律分析与预测辅助

**研究宗旨：找各种规律是为了辅助销量预测。净大定与锁单分别发现规律、检验适用范围、做历史回测，不把两个口径合并。**

净大定使用原始汇总表的“留存大定”（兼容旧字段“净大定”），锁单使用“交车锁单”；如果缺失其中一种字段，明确显示缺失，不使用“大定”替代。小订、大定等原有 Excel 分析保留为补充信息。

在 IDE 中直接运行 analyze_sales_patterns.py，程序参数留空。默认路径相对于项目目录确定，不依赖 IDE 工作目录。

推荐放在 `订单分析/scripts/销量规律`。代码根目录名为 `scripts` 时，数据根目录取其上一级 `订单分析`；其他目录名称则以代码根目录作为数据根目录。日历模块始终从同级的 `generate_html/core` 读取。

## 运行与迁移

运行环境：Python 3.10+、openpyxl。不依赖 Node.js、私有包、Microsoft Excel 或网络服务。

必需文件及目录结构：

```text
订单分析/
  scripts/
    销量规律/
      analyze_sales_patterns.py
      export_excel_openpyxl.py
      report_rules.py
      forecast_insights.py
      export_html.py
      templates/
        patterns.html
        patterns.css
        patterns.js
      report_config.json
    generate_html/core/china_calendar.py
  output_file/鸿蒙智行销量数据汇总.xlsx
```

上面列出的分析、导出模块、配置和 templates 中的三个文件均为必需文件，迁移到内网时一起复制并保留目录结构。requirements.txt 与本说明可选复制。原 .mjs、node_modules、ZIP、缓存和测试文件均不是运行必需文件。

一次无参数执行会固定生成 output_file/鸿蒙智行销量规律分析.xlsx 和同目录的 鸿蒙智行销量规律分析.html。HTML 为单个离线文件，双击可在浏览器中打开；无需启动网站服务。单独分享 HTML 也可使用所有分析交互，若需要从网页下载 Excel，请把两个文件放在一起。分析证据只在内存传递，不生成单独的 JSON、Markdown、预览或日志文件；HTML 内嵌本次净大定和锁单的必要数据。Excel 与 HTML 均先安全写入各自的临时文件，成功后替换对应最终文件；某个文件保存失败时保留该文件上次成功结果，并删除本次创建的临时文件。若 HTML 保存失败而 Excel 已保存，控制台报错而不宣告全流程成功。不会清理整个目录。旧 --out 参数仅兼容接收并提示忽略；--input、--calendar 可选使用，日常运行不需要参数。

## 数据和指标

只读取指定汇总工作簿中的“小订及退订逐日”“当前订单逐日”和“车型基本信息”，不修改源文件，不访问其他业务文件。指标、车型、销售阶段和日期范围动态识别，兼容2021年以来的历史。源工作表和字段名称仍需符合约定。

“留存大定/留存大定来源”优先使用；“净大定/净大定来源”兼容读取并统一命名。小订、大定、留存大定、交车锁单等各指标分别分析；首销和平销分别统计，不把当日下订与当日锁单当成逐单转化率。

真实零值保留；缺失不补零。负值保留在观测合计与审计中，但任何一期包含负值时该周期的倍率不计算。锁单滞后相关仅用共同非负日期，0—3天各组使用相同日期。完整零销量月份仍进入年度分析；全年为零时年度指数留空并说明原因。

## 配置

report_config.json：
- groupBy：auto（默认）、segment（产品档位）、brand（品牌）、energy（能源类型）。
- minGroups/maxGroups：自动选择分类维度的偏好范围，不强行凑组数，不合并或丢弃原始类别。
- mainMetrics：auto（默认）展示本次全部可用指标；可配置为指标名称列表，例如 ["小订数量", "留存大定", "交车锁单"]。未展示的指标会明确列出；配置了本次不存在的指标会报错。

分类只取同一汇总文件“车型基本信息”的原始属性。缺失/冲突单独保留，不通过车型名字猜SUV、价格或能源类型。更换数据可能改变auto选中的分类维度；需要固定口径时显式指定groupBy。

## 结果与验证

首页保留车型分类、全部车型及各车型组读数，并展示每组、指标、阶段中周期数最多的一项摘要。“规律汇总”保留完整结果，列出典型比例、周期P25/P75、车型数、样本数、不同周期数、覆盖年份和历史/验证年度读数。“全年月份”逐一覆盖1—12月。

年度季节性和节假日明细独立导出。即使没有合格样本也保留工作表并给出提示。“数据覆盖与方法”展示覆盖范围、负值等排除原因和节假日日历来源。

典型比例：先车型内取中位数，再车型等权取中位数。全部车型的典型比例也采用等权，不能当成销量加权的整体总量比。P25/P75按日历周期的车型间中位数计算，反映波动，不是置信区间。

留出方向验证：根据数据截至日期选取最近一个完整自然年度，以相同车型、阶段、批次、来源且年度观测完整的序列，将该年和更早完整年度比较。不使用最新未完结年。未满足验证条件时明确显示不足。同方向只表示描述性重复，不能直接认定普遍规律、因果效应或预测参数；还需控制改款、价格权益、供给和长期趋势。

节假日日历独立维护。没有配置的年份不判断普通周与节日，日志会提示缺失年份。

## 日志与测试

控制台日志带时间戳并立即刷新，包含两种预测口径、输入与两个输出路径、日期范围、车型/观测数量、分阶段耗时、滚动回测、各工作表行数和网页导出进度。超过10000行的表会分批报告进度，保存失败给出明确原因。

## 交互网页与预测参考

网页聚焦净大定、锁单两个目标，支持车型组/单车型/阶段/日期筛选、日周月年趋势、1—12月及周内规律、相邻周期倍率、节前节中节后、生命周期、锁单滞后和可搜索分页证据。规律显示典型比例、历史波动范围与有效样本；缺少完整日期或样本时给出说明。车型分类取原表属性，不硬编码品牌或车型名单。

规律用于预测前需要独立检验。新增预测模块按同车型、口径、阶段、批次、来源建立日/周/月序列，以每个历史预测时点之前的数据拟合，和简单基准在相同窗口比较 WAPE、偏差与样本数。最近序列过时或周期未完整时明确提示，不将过去一期伪称下一期预测。网页可查看回测明细，并输入参考销量和单一倍率做情景试算；试算输入由使用者指定，不改变原始观测。

Excel 保留原有工作表，新增“预测辅助”“预测回测明细”；首页优先展示净大定（留存大定）与锁单。网页与 Excel 使用同次计算的预测结果。

历史节假日分析使用双侧同星期对照，可能包含历史事件发生之后的日期，仅用于解释历史，不直接进入滚动预测。周期倍率与P25/P75不等于未来必然增长率或预测置信区间；月份、星期和节日可能重叠，不自动连乘。模型目前不包含价格权益、促销、改款、交付能力等外部特征，需要结合内网真实数据回测后再决定使用。

网页采用列式数据与重复文本字典存储，以减少多年数据的体积；不舍入原始值，不随机抽样丢弃证据。动态表格分页只影响呈现。HTML 内嵌业务数据，迁移和分享范围按源文件相同要求处理。

# 鸿蒙智行订单分析

## 逐日外部预测导入

小订、首销、平销的“预测结论”均提供本地导入入口，支持 .xlsx（第一个可见工作表）和 UTF-8 CSV。表头为“车型（代际）、日期、预测数量”；日期为 YYYY-MM-DD 或 Excel 日期，数量必须是非负整数。可下载 CSV 模板。

只导入当前车型的记录，按维护的阶段日期分组：小订＝小订量，首销＝总大定，平销＝交车锁单。导入卡片位于各阶段预测曲线下方。默认只统计当前日期起的待预测日期，也可选择“整个阶段（包括已过日期）”作为完整阶段外部对照。零值有效；重复日期、无效日期、负数或空数量拒绝整次导入，保留上次结果。导入仅作独立对照，不覆盖实际数据或算法结果。默认合并：同车型、同阶段、同日期更新数值，其他记录保留，并逐行记录来源文件；“替换该车型全部外部预测”会先要求确认，替换当前车型所有阶段的导入记录。单文件最多5MB、20000条记录，同车型合并后也最多20000条。

人工修改参数、外部预测和各阶段导入范围自动保存在当前浏览器本机（按HTML文件路径区分），刷新或重新打开同一路径可恢复，不上传。只恢复人工修改项；真实订单和未修改的自动参数仍使用本次生成数据，避免旧快照覆盖新数据。在“数据来源与时间口径”中可清除当前车型草稿、恢复系统参数，外部导入不受影响。清除导入则同步清除本机保存的外部预测。浏览器限制、空间不足或保存记录损坏时给出提示，不阻断预测；更换浏览器、改变文件路径或清理浏览器存储后需重新设置/导入。

车型与时间参数保持直接展开。顶部至“预测结论 / 预测依据 / 预测打分”采用紧凑布局：宽屏七列参数、中等宽度四列、手机两列；生成时间、字段标签和键盘焦点提示保留。

首销总大定不扣大定退订，锁单单独计算。小转大率为累计小转大除以总小订；实际小订退订率仅显示已有真实值，未来缺失不按0显示。预测依据中的真实区间用实线、估算和预测区间用虚线。

阶段未开始也可预测：小订预测作为首销方法二输入；方法一具备真实进度后才可用。平销开始前优先承接可用的首销方法一，否则方法二，以直接大定乘锁单率估算平销量级；平销开始后维持本车型真实平销锁单优先。预测输入始终标注为预测，不混作真实订单。

读取 Excel 汇总报表，生成一个可离线打开的交互式 HTML 看板。品牌、代际、可用标签和底表全部由 Sheet 自动识别；底表保留 Excel 单元格显示格式，支持搜索、CSV 导出和来源跳转。

## 运行

以下命令在 `generate_html` 文件夹中运行。数据目录按本文件夹的上一级（仓库根目录）定位。

```powershell
python main.py
```

生成完成后会自动使用系统默认浏览器打开 HTML。若只想生成、不自动打开：

```powershell
python main.py --no-open
```

指定输入输出：

```powershell
python main.py --input "..\output_file" --output "..\output_file\鸿蒙智行订单分析汇总.html" --check
```

### 刷新销量预测二次处理数据

原始历史数据、传播名—代际名映射和二次处理文件统一放在仓库根目录的 `input_file\销量预测输入文件`；刷新脚本放在 `generate_html\tools`。在 `generate_html` 文件夹中运行，或在 PyCharm 中直接运行该脚本：

如需按历史时点复盘销量预测，可在 `config.json` 的 `forecast_as_of_date` 填写 `YYYY-MM-DD`；留空则使用运行当天。该配置只改变阶段判定及已发生/未来日期切分，不修改原始订单数据。

```powershell
python tools/refresh_sales_forecast_data.py
```

刷新脚本检查历史文件、车型基本信息、当前订单文件清单与修改时间、转换代码及汇总日期。新增、删除或更新当前订单文件、修改复盘日期或跨日运行都会重新汇总；依赖未变化时跳过。需要无条件重建时使用：

```powershell
python tools/refresh_sales_forecast_data.py --force
```

脚本读取历史整理表、车型基本信息，以及当前订单目录中的《首销期订单节奏》《小订退订分析》《小订选配比例分析》《锁单选配比例分析》，生成 `output_file\鸿蒙智行销量数据汇总.xlsx`。汇总将当前阶段并入车型基本信息，将历史小订与当前小订退订合并为统一逐日表；同车型同日期的小订按《小订选配比例分析》代际by天→《小订退订分析》分时汇总→历史小订by天的顺序读取可用值。数据来源目录对应原始文件和汇总位置。网页销量预测统一从汇总文件读取，继续按原有阶段优先级逐字段回退。空值、真实0、日期和数值格式保持原义。

更新原始Excel后运行main.py即可刷新。汇总中的明细为生成时快照，请在原始文件修改业务数据；直接编辑生成明细会在刷新时被覆盖。网页参数仍在网页人工调整，不将预测值写成已发生真实订单。单独运行刷新脚本可用 `--orders 当前订单目录` 和 `--as-of-date YYYY-MM-DD`。旧名称仅保留兼容读取。

预测汇总仅收录销量预测需要的数据，不重复复制 SKU、选配金等原始明细。累计小订退订统一放在“小订及退订逐日”，不混为当日大定退订；逐日表区分已结束日、当日快照、未来日期及非真实参考曲线。小订和平销的稀疏日期仅在两个有效观测日期之间补缺省的零销量日期，原表明确留空的单元格及覆盖范围以外的日期仍按缺失处理。

历史参考曲线先按历史传播名精确匹配；无精确命中时只接受唯一代际别名，避免同代际不同版本串用曲线。首销已结束时，同车型、同首销窗口且总大定一致的整理表锁单终值优先于逐日回退值。首销“已结束日真实小转大/直接大定”不包含当天全天估算。当天只有大定总数而缺少分项时，分项仅作估算且保持加总一致；两种方法的整数终局与逐日合计一致。D2以后分时滚动优先用本车型最近最多7个完整非D1日、同日历类型优先的分时曲线；否则借用历史D1并提示低置信度。分时比例的分母为同日实际总量或当日预计全天量，不混用其他日期。小订和平销未结束日的已发生量是预测下限，不计为完整真实日。

汇总生成在内存中完成来源整合、计算和压缩快照，再写入最终文件，避免把中间原始Sheet反复保存、重读；最终文件仍通过临时文件原子替换，刷新签名与跨日失效规则不变。

如需每次运行 `main.py` 前自动刷新，将 `config.json` 中以下配置改为 `true`：

```json
"refresh_sales_forecast_data_before_build": true
```

`build_manifest_mode` 控制诊断清单：`off` 为默认高性能模式，`compact` 为紧凑 JSON，`full` 为带缩进的调试格式。

输出文件：

- `output_file\鸿蒙智行订单分析汇总.html`：最终网页（相对于仓库根目录）
- `output_file\build_manifest.json`：可选的解析后页面数据；仅在 `build_manifest_mode` 设为 `compact` 或 `full` 时生成
- `output_file\log\generate_html_YYYYMMDD_HHMMSS.log`：完整运行日志，包含文件读取、主体/模块映射、兼容处理、校验告警和错误堆栈；所有运行日志直接放在 `log` 目录，不再按运行创建子目录
